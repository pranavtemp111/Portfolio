PR-Lens Bot (glint)

A webhook-driven GitHub App that triages pull requests. It fetches the diff and posts a structured review with GREEN, YELLOW or RED tiers, labels and email alerts. Rule-based checks (secret detection, diff shape, account age) are combined with LLM code review, and webhooks are secured with HMAC signature verification.
